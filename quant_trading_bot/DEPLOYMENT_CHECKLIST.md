# Remaining prerequisites for any future live implementation

- [ ] Obtain licensed, contract-identified, raw MES/MNQ history, real fee schedules and an authoritative exchange calendar; audit gaps, quotes and rolls.
- [ ] Confirm the purchased LucidFlex variant, consistency/DLL settings, exact DLL amount, checkout fees, effective rules and relevant account agreement.
- [ ] Confirm intended platform/API authorization and conduct restrictions. General automation permission is not permission for a particular integration.
- [ ] Register real-data trials, run purged chronological/nested comparisons and meaningful dependence-aware uncertainty/stress analysis.
- [ ] Freeze selection and evaluate one untouched market holdout. Reject unprofitable or unstable candidates honestly.
- [ ] Complete extended authorized real-feed paper testing, accounting reconciliation, drift checks, disconnection/roll/holiday tests and review of execution differences.
- [ ] Implement durable streaming state, missing-arrival watchdog, exchange-side protective orders, actual rejection/cancel acknowledgments and portfolio-wide correlated risk.
- [ ] Verify clean runtime/deployment environment and resources; separately validate Linux/WSL/Docker if used.
- [ ] Obtain explicit user authorization before implementing/activating real-money execution. The current project has no live adapter or activation switch.

No deployable model is currently selected. Functional tests, synthetic leaderboards and funded-account scenarios satisfy none of the real-market evidence requirements by themselves.
